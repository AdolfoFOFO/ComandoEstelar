# Equipo 03 · Comando Estelar Sinaloa

Landing page estática (HTML, CSS y JavaScript). No necesita instalar nada.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `comando-estelar-equipo03`).
2. Sube TODO el contenido de esta carpeta a la raíz del repositorio (`index.html` debe quedar en la raíz).
3. Ve a **Settings → Pages**.
4. En **Source** elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
5. En uno o dos minutos tu sitio estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Qué personalizar

- **Fecha de lanzamiento, redes y correo:** al inicio de `js/main.js` (objeto `CONFIG`).
- **Integrantes del equipo:** sección `#tripulacion` en `index.html` (nombre, puesto y descripción).
  Para usar fotos, sube las imágenes a `assets/img/` y cambia el `<div class="cadete__foto">` por una `<img>`.
- **Colores:** variables al inicio de `css/styles.css` (`--verde`, `--morado`, `--blanco`).

## Estructura

```
index.html
css/styles.css
js/main.js
assets/img/  (logos, favicon e iconos)
.nojekyll
```
